# Couverture du dashboard

Fais le point pour Michel, en moins de 10 lignes :

- `npm run check` : erreurs et alertes de la spec.
- `npm run couverture -- --anomalies` : mesures alimentées, partielles, non alimentées ; catégories manquantes qui débloquent le plus ; anomalies du catalogue qui faussent des chiffres.
- `npm run questions` : nombre de questions ouvertes, et les 3 qui comptent le plus pour le dashboard.

Termine par la prochaine action recommandée.
